# Skint

Skint is a household money tracker that replaces arcane spreadsheers with a browser app. It runs in Docker and stores its data in a SQLite file on a Docker volume on your own machine.

Website: https://skint.site

## Download

Download `skint.zip` from the [latest release](https://github.com/murraycollier/skint/releases/latest). It contains everything you need: the app source, the Dockerfile, `docker-compose.yml` and `.env.example`.

Then follow the [setup guide](https://skint.site/get-started/) to install Docker and run the app.

## Need help?

Check the [setup guide](https://skint.site/get-started/) first. If that doesn't solve it, [open an issue](https://github.com/murraycollier/skint/issues/new/choose).
